One line of wedding vows for a robot couple — at most 160 characters.
`VOW.txt` holds the vow; `main.ts` checks it is a single line of 1 to 160
characters and writes it to `/output/entry.txt` for the judge to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
